# RM-app — правила за Claude Code

## Какво е
Личен PWA инструмент на регионален мениджър (ТеМАХ). Единствен файл index.html
(HTML+CSS+JS), sw.js, manifest.json. Хостинг: GitHub Pages
(tenchotenev13-afk.github.io/RM-app/). Няма build, няма npm, няма тестове.

## Данни
- Задачи на РМ: const BASE (по ден от седмицата).
- Задачи на обект Кърджали (885): const REG_885 — източник е docs/Регламент_Кърджали_без_управител.md.
  Не измисляй задачи; редове с [?] от регламента не влизат в кода.
- Бюлетин/задачи от портала: само четене от Supabase на Tmax-store-portal (SB_URL, anon key).
  Никога не пиши в тази база оттук.
- Отметки: localStorage 'tm-done', дневно нулиране в checkDailyReset().

## Код
- Следвай стила на файла. Без emoji в JS стрингове.
- Хирургични промени; не пренаписвай функции, които работят.
- При промяна на index.html увеличи CACHE в sw.js (temax-vN → vN+1), иначе PWA сервира стар код.
- Не пипай OneSignal/нотификациите освен при изрична задача.

## Работа
- Задачите идват като TASK блок: КОНТЕКСТ / ПРОМЕНИ / ТЕСТ / ДОСТАВКА. Прави само описаното.
- Commit без push. Върни SHA и кратък diff summary. Push само след изрично „пушни“.
- Ако нещо в задачата противоречи на кода — спри и питай, не предполагай.
